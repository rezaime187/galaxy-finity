Interaksi stream.
Diatur dari PC kamu.

Galaxy Finity adalah aplikasi desktop untuk membantu kreator mengelola interaksi TikTok LIVE, media lokal, dan overlay browser pada komputer yang sama.

Kenali aplikasinya ↓
01 / INTERAKSI

Media milikmu

Atur gambar, audio, video, dan alert. File yang dipilih disalin ke penyimpanan lokal aplikasi untuk dipakai pada interaksi.

02 / OVERLAY

Tampilan untuk stream

Gunakan Browser Source pada PRISM, OBS, atau TikTok Studio untuk menampilkan chat, ranking, antrean musik, dan penghitung Win/Lose ML.

03 / PROFIL

Login atas izinmu

Integrasi Login Kit TikTok ditujukan untuk mengambil foto dan nama profil setelah pengguna memberikan izin. Koneksi LIVE diatur terpisah.

Cara kerja

Aplikasi lokal, koneksi seperlunya.

  1. Jalankan Galaxy Finity di Windows dan atur media atau overlay.
  2. Tambahkan link server lokal aplikasi sebagai Browser Source di perangkat yang sama.
  3. Hubungkan ke sesi TikTok LIVE untuk menerima event yang tersedia melalui konektor.
Status pengembangan

Aplikasi belum tersedia sebagai unduhan publik di website ini. Login resmi sedang diuji melalui konfigurasi developer/sandbox. Login profil tidak memberikan akses otomatis ke katalog gift atau paket stiker; ketersediaannya mengikuti konektor dan akses TikTok. Deteksi hasil ML menggunakan OCR dan dapat memerlukan koreksi manual.

Privasi dan dukungan

Media dan pengaturan utama disimpan di PC. Layanan opsional seperti suara cloud dan musik memerlukan koneksi ke penyedia terkait. Pelajari rincian di Kebijakan privasi dan Syarat penggunaan.

Untuk pertanyaan dan laporan masalah, hubungi pengelola melalui GitHub Issues Galaxy Finity. Jangan mengirim password, token, atau API key ke laporan publik.

Galaxy Finity adalah proyek independen, tidak berafiliasi dengan atau disponsori oleh TikTok, Spotify, YouTube, maupun penyedia layanan lain.
