Transparansi data

Kebijakan privasi

Berlaku: 9 November 2026 · untuk Galaxy Finity desktop v1.1 dan website informasi ini.

Galaxy Finity dikelola oleh rezaime187. Dokumen ini menjelaskan penggunaan data pada versi saat ini. Kontak: GitHub Issues Galaxy Finity.

1. Data yang digunakan

  • Login profil TikTok: dengan izin user.info.basic, aplikasi meminta pengenal akun (open_id), foto profil, dan nama tampilan dari API resmi. Nama dan URL foto digunakan pada header; pengenal akun hanya dibaca untuk memvalidasi respons profil.
  • Otorisasi: Client Key, Client Secret, kode otorisasi, access token, dan refresh token diproses untuk login dan permintaan profil. Login dilakukan di halaman TikTok pada browser, bukan dengan mengisi password TikTok ke Galaxy Finity.
  • Event LIVE: saat konektor terhubung, aplikasi dapat menerima username/pengenal pengguna, nama, URL avatar, komentar, metadata stiker/gift, jumlah coin, likes, follow, dan informasi viewer/room yang tersedia.
  • Konten lokal: media pilihan pengguna, pengaturan, interaksi, riwayat aktivitas, antrean musik, skor, dan gaya overlay digunakan untuk menjalankan fitur yang dipilih.
  • Tangkapan game: bila dipilih pengguna, frame area layar/perangkat video dikirim ke server lokal aplikasi untuk OCR penghitung ML.

2. Tujuan pemrosesan

Data dipakai untuk menampilkan profil, chat dan overlay, memicu interaksi, menghitung ranking, membaca komentar, mengelola request musik, dan mengenali teks hasil pertandingan. Versi saat ini tidak menyediakan pengiriman balasan chat ke TikTok. Website informasi ini tidak memiliki formulir login atau pengunggahan data.

3. Penyimpanan dan masa simpan

Pengaturan, media, cache katalog, serta sebagian riwayat/sesi disimpan pada PC, di folder %APPDATA%/Galaxy Finity/studio-data untuk aplikasi desktop. Data tersimpan dapat tetap ada setelah aplikasi ditutup dan setelah uninstall sampai dihapus oleh pengguna. Jenis riwayat tertentu dibatasi atau diganti saat sesi berubah; tidak semua event disimpan permanen.

Pada v1.1, kredensial Login Kit, token TikTok, serta konfigurasi API key yang dimasukkan lewat UI hanya berada di memori proses dan hilang saat aplikasi berhenti. Foto profil dimuat dari URL TikTok/CDN; browser atau sistem dapat menyimpan cache resource. Jika pengguna mengatur kredensial lewat lingkungan proses atau alat lain, penyimpanan di luar aplikasi menjadi tanggung jawab pengguna.

4. Koneksi ke pihak ketiga

  • TikTok menerima permintaan otorisasi, token, dan profil melalui API resminya. Foto dan gambar dapat dimuat dari CDN.
  • Konektor TikTok LIVE tidak resmi dapat menghubungi TikTok dan layanan signing pihak ketiga. Internet, username, dan informasi room digunakan untuk koneksi; konektor dapat berubah atau dibatasi.
  • Jika suara ElevenLabs/Azure dipilih, teks yang disintesis dikirim ke penyedia tersebut. Suara browser juga dapat memakai layanan daring. Musik YouTube/Spotify menggunakan layanan penyedia terkait.
  • CSS kustom atau resource eksternal yang ditambahkan pengguna dapat membuat permintaan jaringan. Font/resource daring dan pemuatan gambar mengikuti kebijakan penyedianya.

Versi lokal ini tidak memiliki backend cloud Galaxy Finity untuk menyimpan media/event, serta tidak memasang pelacak analitik khusus. Website statis ini dihosting oleh GitHub Pages; GitHub dapat memproses data teknis kunjungan sesuai kebijakan privasi GitHub. Kebijakan penyedia lain berlaku pada layanan mereka.

5. Kontrol dan penghapusan

Gunakan Logout untuk menghapus sesi profil lokal dan meminta pencabutan token TikTok. Bila pencabutan belum terkonfirmasi, aplikasi memberi pemberitahuan; izin juga dapat dikelola dari akun TikTok. Keluar sepenuhnya dari aplikasi menghapus kredensial yang hanya ada di memori.

Untuk menghapus data yang tersimpan, keluar sepenuhnya, buka folder data melalui menu aplikasi sebelum menutupnya, lalu hapus data lokal beserta cadangan yang tidak ingin disimpan. Menghapus item di UI tidak selalu menghapus file media fisik atau cadangan. Penghapusan di PC tidak menghapus data asal pada TikTok atau penyedia lain. Ajukan permintaan terkait layanan pihak ketiga kepada penyedia terkait.

6. Keamanan dan pengungkapan di stream

Server overlay mendengarkan loopback pada PC. Jangan mengeksposnya ke internet atau membagikan folder data/kredensial. Informasi yang ditampilkan oleh overlay dapat terlihat oleh penonton saat disiarkan atau direkam; pengguna bertanggung jawab menentukan konten yang ditampilkan. Jangan memasukkan data rahasia ke CSS atau alert.

7. Kontak dan perubahan

Ajukan pertanyaan atau permintaan privasi melalui GitHub Issues Galaxy Finity. Karena Issues bersifat publik, cukup jelaskan permintaan secara umum tanpa token, password, email pribadi, atau data viewer sensitif. Kebijakan akan diperbarui bila perilaku aplikasi berubah; tanggal berlaku dicantumkan di atas.
